# saaradhi-api

NestJS API for Saaradhi. Prepare-only: nothing here submits a form or payment on the user's behalf.

```bash
npm install
npm run start:dev     # http://127.0.0.1:3000/health
npm test
npm run test:e2e
```

Environment comes from `api/.env` (copy the root `.env.example`). Never commit real keys.
Project rules: see the root [CLAUDE.md](../CLAUDE.md).
